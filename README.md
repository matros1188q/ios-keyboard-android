# iOS Keyboard for Android

Native Android input-method app styled after the iPhone keyboard.

The full Android Studio project is stored in `ios-keyboard-project.zip`. GitHub Actions unpacks it and builds a debug APK automatically on each push.

## Download the APK
1. Open the **Actions** tab.
2. Select the latest **Build Android APK** run.
3. Wait for the green check mark.
4. Download the `ios-keyboard-debug-apk` artifact.
5. Extract the downloaded artifact ZIP; it contains `app-debug.apk`.

The APK is an unsigned debug build for direct testing and personal installation.
