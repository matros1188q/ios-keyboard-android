# iOS Keyboard for Android

Нативная экранная клавиатура Android в стиле iPhone. Это Android IME, поэтому её можно выбрать системной клавиатурой и использовать в полях ввода разных приложений.

## Реализовано
- Русская и английская раскладки с переключением клавишей 🌐.
- Цифровая и дополнительная символьная раскладки.
- Shift, удаление, пробел, запятая, точка и системное действие Enter.
- Панель быстрых слов и отдельная панель эмодзи.
- Светлая/тёмная тема, настраиваемая вибрация и звук.
- Локальная обработка текста; приложение не запрашивает разрешение INTERNET.

## Сборка APK
Каждый запуск GitHub Actions публикует артефакт `ios-keyboard-debug-apk`.
Открой **Actions → Build Android APK → последний успешный запуск → Artifacts** и скачай APK.

## Установка
1. Установи `app-debug.apk` на Android.
2. Открой iOS Keyboard и нажми «1. Включить iOS Keyboard».
3. Разреши клавиатуру в системных настройках Android.
4. Нажми «2. Выбрать клавиатуру» и выбери iOS Keyboard.

Это первая рабочая версия. Визуальный стиль близок к iOS, но системные шрифты/эмодзи и поведение Android могут отличаться от iPhone.
